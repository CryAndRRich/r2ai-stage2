<data_contract>
- `to_num(s)` is ALREADY DEFINED — do not redefine it, just call it. It parses a cell into a float using the Vietnamese convention ("." thousands, "," decimal, "(1.234)" = −1234, "12,5%" = 12.5, and also the English OCR variant "1,234,567"), returning `None` for anything that is not a number.
- `to_num` is a PLAIN FUNCTION, not a pandas method. Correct: `to_num(df1.iloc[3, 2])`, `[to_num(v) for v in df1.iloc[:, 2]]`, `df1.iloc[:, 2].map(to_num)`. Wrong: `series.to_num()`.
- NEVER `.astype(float)` / `pd.to_numeric(...)` on these cells — `"1.234.567"` raises `ValueError`. `to_num` is the only correct converter; skip cells where it returns `None`.
- A header cell may join several header tiers with " | " (`Số cuối năm | Giá trị`, `31/12/2018 | Triệu VND`): first part = period group, later parts narrow it (sub-column, unit).
- Balance sheets have a "Số cuối năm" and a "Số đầu năm" column; "cuối năm N" is end-of-year of report N, "đầu năm N" = end-of-year N−1. "Năm nay"/"Năm trước" work the same way in income statements.
- OCR has diacritic errors: match row labels loosely (`.str.contains(..., case=False, na=False)`), not by equality.
</data_contract>

<precomputed_hints>
Two comment lines above each table are computed by the pipeline with deterministic rules (not by a model). TRUST and follow them — a wrong period column or a skipped unit conversion is the most common way to produce a number that runs but scores wrong.
- `<!-- Cột theo kỳ: 1=kỳ 31/12/2018 (VND) 2=kỳ 01/01/2018 (VND) | CỘT ỨNG VỚI KỲ ĐƯỢC HỎI -> .iloc[:, 1] -->` — entries are `<positional index>=<period> (<unit>)`. Read the value from the column index after `CỘT ỨNG VỚI KỲ ĐƯỢC HỎI` — not the last column, not the biggest number in the row. If it says `chưa xác định được`, choose the column yourself by matching header text to the period in the question.
- `<!-- Đổi đơn vị: … -> ÷ 1.000.000 (nhân với 1e-06) … -->` — multiply the value you read by exactly that factor before assigning `result`. `KHÔNG cần` / `KHÔNG đổi` means do not scale. `chưa suy được đơn vị` means read the unit from header/context yourself and convert to the unit in `- Đơn vị đáp án:`.
- Each hint describes ONE table: when combining tables, apply each table's own column index and factor.
</precomputed_hints>

<semantic_rules>
- A difference asked without a direction is a non-negative magnitude; with an explicit direction it keeps its sign.
- Growth in percent = (new - old) / abs(old) * 100.
- A percentage answer is returned ON THE PERCENT SCALE: for "… là bao nhiêu phần trăm?" with a ratio of 0.9, `result = 90.0` is correct and `0.9` is wrong. Ratios asked as a coefficient ("hệ số", "lần") are NOT multiplied by 100. Both operands of a ratio must be in the same unit — then no unit conversion is needed (the factors cancel).
</semantic_rules>

<reliability_rules>
- Check a filtered DataFrame is not empty (`len(filtered) > 0`) before `.iloc[0]` / `.iloc[-1]` / `.values[0]`. A filter matching zero rows means the label is not in THIS table (wrong table), not that you should guess an index.
- Check `to_num(...)` is not `None` before arithmetic (`None / x` raises `TypeError`); `None` means the wrong cell/row/table was picked.
- NEVER take "the last numeric value of the row" (`vals[-1]`, `row.iloc[-1]`, `max(vals)`): the last column is usually another period or a sub-column (provision, %, total), so the code runs but the answer is wrong. Address the column by the hinted index (or by header text you matched yourself).
- Do NOT round, not even the final value: the answer is accepted only within 0.02% RELATIVE error, so rounding a small answer (a ratio, a coefficient) to 2 decimals can already fail. Keep full precision — `result = float(value * SCALE)`.
- Assign exactly ONE final numeric scalar to `result` (float or int — never a string, Series, or DataFrame). Never assign `None`: it scores as a failure.
- Use every provided table that is relevant; if only one is, use only that one.
- Standard pattern — find the row by label, read the hinted column, apply the hinted factor, and loop over the other tables when the label is missing (the right table is often not `df1`):
```python
COL = 1            # chỉ số từ chú thích "CỘT ỨNG VỚI KỲ ĐƯỢC HỎI -> .iloc[:, K]"
SCALE = 1e-06      # hệ số từ chú thích "Đổi đơn vị" (1.0 nếu chú thích nói KHÔNG cần đổi)
value = None
for _df in dfs.values():
    hit = _df[_df.iloc[:, 0].astype(str).str.contains("<nhãn dòng>", case=False, na=False)]
    if len(hit) == 0:
        continue
    row = hit.iloc[0]
    if COL < len(row):
        value = to_num(row.iloc[COL])
    if value is None:  # ô đó rỗng -> lấy số ĐẦU TIÊN của dòng (không phải số cuối)
        nums = [to_num(v) for v in row.tolist()]
        nums = [v for v in nums if v is not None]
        value = nums[0] if nums else None
    if value is not None:
        break
result = float(value * SCALE) if value is not None else 0.0
```
